# Working rules
- Explain in German, keep explanations short. Code, comments and commits in English.
- Only read files needed for the task. Never scan the whole repo unless asked.
- Use search (grep/glob) to find the right spot before opening large files; read only the relevant section.
- Make small, targeted edits instead of rewriting whole files.
- Do not start subagents unless the task clearly requires it.
- No long summaries at the end: one or two sentences on what changed.
- Ask before deleting or overwriting files.
- If a task is unclear, ask one short question instead of exploring.
